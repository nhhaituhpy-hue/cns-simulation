# DME 1119A Standalone Scenario Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thay thế luồng DME author/exam cũ bằng bộ Scenario Parameters độc lập cho DME 1119A, cho phép giám khảo tạo/import/export JSON, nạp tình huống session-only và để học viên xử lý đến trạng thái `SOLVED` trên PMDT.

**Architecture:** Scenario domain mới dùng `Dme1119aPersistedConfig` làm baseline cấu hình, fault injection có kiểu rõ ràng làm nguồn lỗi vật lý, Zustand store quản lý lifecycle Apply/Restore/End, engine hiện tại tiếp tục là nguồn tính Config → Monitor → Alarm. UI chỉ trình bày và gọi domain/store; persistence được chặn trong toàn bộ phiên Scenario.

**Tech Stack:** TypeScript, Next.js 16.2.11 App Router, React 19, Zustand 5, Vitest 4, Testing Library, Playwright/browser controller, CSS PMDT hiện có.

**Spec:** [`docs/superpowers/specs/2026-08-26-dme1119a-scenario-design.md`](../specs/2026-08-26-dme1119a-scenario-design.md)
